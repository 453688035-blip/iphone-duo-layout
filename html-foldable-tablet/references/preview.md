# 设备预览与目录

顶部「苹果 / 华为」直接切换对应的设备与姿态。查看 [设备列表、模拟尺寸和素材来源](huawei.md)。

用 [starter.html](../assets/preview/starter.html) 作为可运行接入示例。保留原页面的 DOM 和交互，将其包在 `.app-shell`；三个 `duo-preview:…` 标记对分别放在样式、外层预览结构和页面脚本后。目录模板使用 `#tocBtn`、`#tocScrim`、`#tocSheet`、`#tocClose`、`#tocList` 与原页 `nav a[href^="#"]`。非阅读页按真实导航结构改写目录适配，避免制造多余导航。要生成可离线打开的文件，从技能目录执行：

```sh
cp assets/preview/starter.html /tmp/duo-starter.html
node scripts/update-preview.mjs /tmp/duo-starter.html
```

`--report` 只给本项目报告附加布局适配。生成器仅替换三个标记区，可以重复执行；正文、交互脚本和数据保留。预览代码、姿态元数据与 WebP/SVG 素材在 [assets/preview](../assets/preview/)。

切换器在所有模式下固定于顶部居中。「原始内容」显示输入页面，`pose=web` 及旧链接 `pose=outer` 和 `pose=inner` 继续可用。预览以 1 pt 对 1 CSS px 建立逻辑窗口，再整体缩放。移动端设计和实现可复用设备尺寸、状态栏方向与保留区，原生交付仍使用运行时窗口、安全区及活动折叠区。Web 交付仍以浏览器实际视口为准。

## 复现与验收

- 品牌按钮与设备图标保持单行。窄屏可横向滑动设备图标，设备名称保留在悬停提示和无障碍标签中。用 `.dp-window.clientWidth/Height` 检查逻辑窗口。正文滚动区从实际顶部状态栏下方开始，应用标题栏固定在滚动区顶部。外屏标题栏背景可以延伸到侧边轨，文字与交互热区继续避让镜头和控件。
- 正文背景延伸到圆角屏幕边缘。底部渐变与 Home 指示条作为独立层，渐变不接收触摸。按可见系统控件与应用导航留出末项滚动余量；没有底部导航的页面使用紧凑的 Home 指示条空间。滚到表格中段检查上下边缘，再滚到底检查末项能否完整显示和点击。
- 在每种姿态先滚到中段，再点击目录、滚到末项、以 Escape／完成／遮罩关闭。比较关闭前后的 `window.scrollY` 与 `dpScreen.scrollTop`；焦点要回到实际触发按钮。Tab 不得进入底层页面。
- 滚到资料末尾，验证最后一个链接完整出现在正文区域内并可点击。Home 指示条所在的固定区域不应透出或挡住正文。
- 点击目录条目只滚动当前正文容器。浮层应位于屏幕圆角内，短横屏时列表内部可滚到末项，关闭按钮可达；完整按钮避开状态区、镜头与底部指示条。
- 从外屏切到内屏，再切回原始内容：检查章节锚点、输入值、选中状态和展开行。同一个 DOM 用于所有姿态，无需重新渲染页面内容。
- 检查竖屏窄宿主、短横屏宿主、桌面宿主和真实移动端网页。仅浏览器验证通过时，记录为浏览器模拟；另列 Safari、键盘、设备和实测折线的未测项。

在完整项目工作区可运行 `node --test html-foldable-tablet/scripts/update-preview.test.mjs`，检查设备预设尺寸和离线打包。若环境已安装 Playwright 和对应浏览器，可运行 `node html-foldable-tablet/scripts/preview-browser-check.mjs` 回归两份报告和 starter；设置 `DUO_BROWSER=webkit` 切换浏览器内核，`DUO_SCREENSHOTS` 指定截图目录。

姿态图标按预设语义命名。外屏横向和外屏竖向共用 `icons/duo-outer-portrait.svg`，横向按钮由 `rotateIcon` 旋转。更换图标名称时同步 `poses.json` 并重新生成离线 HTML。

## 移动应用预览

- 苹果状态栏按姿态复用本技能的 `duo-levels-vertical.svg`、`duo-levels-horizontal.svg`、`iphone-wifi.svg` 和 `iphone-battery.svg`。闭合横屏沿用设计套件示例，左右分屏展示应用窗口。iPhone 18 Pro 使用灵动岛两侧的状态栏，并与应用标题分开。

- 状态模块、镜头、机框和 Home 指示条属于设备层。页面底色延伸到屏幕圆角和保留区。横排状态模块可与应用标题共用一行，按实际边界为标题和按钮留空。
- 有实际操作的侧轨可复用同一组任务按钮。闭合横向先检查右下镜头；仅预留设备占用的区域。分屏示例在没有实测边缘占用时使用整个子窗口，保留外侧圆角和共享边直角。
- 半折按任务分区。书本姿态可在第二屏放实际业务入口，面板随内容高度收起；桌面姿态可把操作栏和输入区放到下半区。背景贯通折线两侧，完整交互热区避开折带。装饰用细线即可。
- 正文滚动边界按操作栏实际高度和位置计算，保留小段末项间距。滚到中段和末尾分别检查标题、图表、卡片和操作栏。雷达图的标签和数值围绕图形，卡片按钮随文字排布。
- 顶部品牌和姿态切换器使用明确的文字及背景色。普通文字对比度至少 4.5:1，检查默认、悬停、选中和键盘焦点。原始内容使用低亮度的选中底色，图标姿态可继续使用高对比度的选中态。

### 对话页与固定输入区

- 在设备屏幕容器统一绘制友福背景，状态栏、标题区、右侧避让区和居中输入区共用这一层。宽屏可限制输入区内容宽度，背景仍延伸到屏幕圆角。检查输入区底衬和伪元素是否造成左右色带。
- 正文可见高度按标题、固定输入区及键盘的实际边界计算。贴边悬浮操作叠在正文上，位置变化时正文高度保持稳定。滚到任务表格末尾，确认最后一行和卡片操作完整可见。
- 「查看原业务」沿右侧悬浮，可在标题与输入区之间上下拖动。闭合横屏和书本半折分别按可用内容区和当前半屏定位，避免压住镜头、侧边导航或折线。验证轻点仍能打开表单，拖动结束时保持在对话页。
- 主页和回复页的快捷胶囊沿用原有紧凑高度，保持单行。窄屏横滑到末尾，检查最后一个入口可完整显示并点击。回复页省去问候区，消息从标题栏下方开始滚动。
- Duo 外屏及展开横屏的对话导航沿状态模块中心线竖排，优先返回和关闭。展开竖屏与桌面半折共用顶部标题和横向状态区。桌面半折的消息在上屏滚动，输入区放在折线下；书本半折的业务入口标记当前所在模块。iPhone 18 Pro 的标题位于灵动岛状态栏下方。
